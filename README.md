## 🚀 Overview
NexOra is a state-of-the-art web analytics platform built for the modern web. It is designed to be privacy-friendly, highly performant, and incredibly easy to integrate. Say goodbye to complex dashboards—NexOra provides actionable insights at a glance with a beautiful, premium user interface.

## ✨ Key Features
- **Privacy First:** Cookie-free tracking that respects user privacy and complies with modern regulations.
- **Real-Time Insights:** Watch your traffic and events as they happen on an intuitive, live dashboard.
- **Smart Teamwork:** Easily manage teams, share dashboards, and schedule automatic email reports.
- **Premium Design:** A modern, meticulously crafted UI with smooth scroll transitions and elegant typography.
- **Seamless Integration:** Get started by pasting a single snippet of code into your website.

## 🛠️ Technology Stack
- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Library:** [React](https://reactjs.org/)
- **Styling:** Vanilla CSS (App.css & globals.css) with CSS Variables for a fully custom design system.
- **Icons:** [Lucide React](https://lucide.dev/)
- **Animations:** Custom CSS transitions and smooth scrolling integration.

## 📦 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/nexora.git
   cd nexora
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **View the application:**
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
